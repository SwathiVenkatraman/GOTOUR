# 🌍 GOTOUR - Travel Booking Website

GOTOUR is a travel booking website that allows users to explore destinations, book tours, and manage their travel plans — all from a clean and modern web interface.

---

## ✨ Features

- 🏠 **Front Page** – Attractive landing page showcasing travel destinations
- 📍 **Destinations** – Browse popular travel destinations
- 📅 **Booking System** – Book tours and travel packages
- 👤 **Login & Sign In** – User authentication pages
- 🔑 **Forgot Password** – Password recovery page
- ℹ️ **About Us** – Information about GOTOUR
- ✅ **Booking Confirmation** – Success page after booking
- 💳 **Payment Page** – Secure payment interface

## 🚀 How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/SwathiVenkatraman/GOTOUR.git
   ```

2. **Open in VS Code**
   ```bash
   cd GOTOUR
   code .
   ```

3. **Run with Live Server**
   - Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension in VS Code
   - Right-click on `frontpage.html`
   - Select **"Open with Live Server"**

4. **Or simply open in browser**
   - Double-click `frontpage.html` to open directly in your browser
